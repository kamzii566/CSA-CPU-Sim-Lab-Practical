# Practical 4: SUB Operation on Two User-Entered Numbers

## Aim
To write and execute an assembly language program to subtract the second user-entered number from the first number using Mano's Basic Computer in CPU Sim.

## Instructions Used
- `INP` – Read a number from the input.
- `STA` – Store the accumulator value in memory.
- `CMA` – Complement the accumulator.
- `INC` – Increment the accumulator.
- `ADD` – Add a value to the accumulator.
- `OUT` – Display the result.
- `HLT` – Stop execution.

## Algorithm
1. Read the first number and store it in memory.
2. Read the second number.
3. Complement the second number.
4. Increment it to obtain its two's complement.
5. Add the stored first number.
6. Display the result.
7. Halt the program.

## Program File
`P04_SUB.a`

## Expected Result
The program displays the first number minus the second number.

## Software Used
CPU Sim – Mano's Basic Computer.
