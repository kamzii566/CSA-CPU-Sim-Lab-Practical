# Practical 6: Basic Computer Simulation Using CPU Sim

## Aim
To execute the given program using CPU Sim and observe the changes in registers and memory.

## Software Required
CPU Sim

## Theory
CPU Sim is a computer simulator that helps us understand the execution of instructions in a basic computer. It allows us to observe registers, memory locations, and program execution step by step.

## Procedure
1. Open CPU Sim.
2. Load the Basic Computer machine.
3. Load or enter the program specified in the practical.
4. Execute the program using the available execution controls.
5. Observe the register and memory values.
6. Record the output and verify the result.

## Result
The program was executed and the behavior of the basic computer was observed using CPU Sim.
