# Practical 5: Basic Computer Instructions Using CPU Sim

## Aim
To study and execute basic computer instructions using CPU Sim and observe the changes in registers and memory.

## Software Required
- CPU Sim

## Theory
CPU Sim is a simulator used to understand the working of a basic computer. It allows us to execute machine instructions and observe the values stored in registers and memory.

## Instructions Studied
- CLA: Clear the accumulator.
- CLE: Clear the E register.
- CMA: Complement the accumulator.
- ADD: Add the contents of memory to the accumulator.
- STA: Store the accumulator in memory.
- INP: Input data into the accumulator.
- OUT: Display the accumulator's value.
- HLT: Halt program execution.

## Procedure
1. Open CPU Sim.
2. Load the Basic Computer machine.
3. Enter the program and required input values.
4. Execute the program using the simulator.
5. Observe the register values and output.

## Result
The basic computer instructions were studied and executed using CPU Sim.
