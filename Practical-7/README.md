# Practical 7: Basic Computer Using CPU Sim

## Aim
To execute the assigned program using CPU Sim and observe the operation of the basic computer.

## Software Required
CPU Sim

## Theory
CPU Sim is a simulator used to study computer instructions, registers, memory, and program execution.

## Procedure
1. Open CPU Sim.
2. Load the Basic Computer machine.
3. Enter the program specified in the practical.
4. Execute the program and observe the register values.
5. Record the output.

## Result
The assigned program was studied using CPU Sim.
